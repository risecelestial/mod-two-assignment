
Module 2 Assignment: Responsive, Accessible Component

Project Description

This project is a responsive collection of three book recommendation cards. It practices semantic HTML, mobile-first CSS, responsive layouts, accessibility, and JavaScript DOM interaction.

Technologies Used

- HTML5 for semantic page structure
- CSS3 for styling and responsive layout
- CSS Grid for arranging the cards
- Vanilla JavaScript for interactive buttons

Responsive Design

The page starts with one column for mobile screens. At a minimum width of 700 pixels, CSS Grid changes the layout to three columns.

The stylesheet uses CSS custom properties for reusable colors, spacing, and design values.

 Accessibility

- Semantic HTML and a logical heading structure
- Meaningful alternative text for images
- Buttons with accessible expanded-state information
- Visible keyboard focus indicators
- Readable text and spacing

JavaScript Interaction

Each book card has a Show more / Show less button. Clicking the button displays or hides additional information for that book.

Project Files

- index.html — page structure
- styles.css — styling and responsive layout
- app.js — interactive button behavior
